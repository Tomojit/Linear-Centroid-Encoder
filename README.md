# Linear-Centroid-Encoder
A supervised linear dimensionality reduction technique. It is a linear counter part of Centroid-Encoder
Instruction to use the code package.

Requirements:

Python. The code was tested in versions: 3.7.3 & 3.7.4

Numpy version 1.16.4
Scipy version 1.3.0
Matplotlib version 3.1.0
ipython (optional) version 7.6.1
Notes:

The mouse_bladder_cell.h5 file is given with the package.
The code to read the h5 file is provided. 
Run the "RunClassificationWithSLCE.py" from iPython (that's what I do). It can be run directly frim Python command line
How to run the code:

Download the code.
Make sure all the requirements are satisfied.
To run the script from ipython run the commands: a. run RunClassificationWithSLCE.py
